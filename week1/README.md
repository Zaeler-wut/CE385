1-1 มีการสร้างตัวแปรชื่อ name , age, major เก็บค่า  ชื่อ, อายุ และสาขา ตามลำดับ จากนั้นเขียนคำสั่งแสดงผลในconsole 
    โดยใช้ console.log();

1-2 กำหนดตัวแปร string, number, boolean, empty, notDefined ให้เก็บเป็นข้อมูลชนิดต่างๆที่แตกต่างกัน
    และนำมาแสดงผลใน console  โดยมีการใช้ typeof เพื่อบอกชนิดของข้อมูลในตัวแปรนั้นๆ

1-3 กำหนดตัวแปร math, sci, eng ไว้เก็บคะแนน จากนั้น สร้างตัวแปร sum สำหรับเก็บผลรวมของคะแนน และ avg สำหรับเก็บผลค่าเฉลี่ย
และนำ sum กับ avg มาแสดงผล จากนั้นแสดงผลว่า คะแนนเฉลี่ย >= 80 หรือไม่(true,f..)
