ให้ผู้ใช้คุยกับ AI เพื่อดึงข้อมูลจากฐานข้อมูลได้โดยตรงผ่านข้อความธรรมดา เมื่อผู้ใช้ส่งข้อความเข้ามาที่ /chat ระบบจะส่งต่อไปให้ฟังก์ชัน askAI เพื่อให้ AI วิเคราะห์ความต้องการก่อนที่ AI จะตอบ ระบบจะส่ง schema ของฐานข้อมูลจาก Prisma ให้ AI เพื่อให้รู้ว่ามี model และ field อะไรบ้าง
AI ถูกกำหนดกฎให้ใช้ tool ชื่อ query เท่านั้นในการดึงข้อมูล และห้ามเขียน SQL หรือเดาเอง
เมื่อ AI ต้องการข้อมูล มันจะเรียก query tool พร้อมระบุ model, action และ args
ระบบจะรับคำสั่งนี้แล้วไปเรียก runQuery ซึ่งใช้ Prisma ในการ query database จริง ก่อน query จะมีการ validate input ด้วย Zod เพื่อป้องกันคำสั่งที่ผิดหรืออันตราย ผลลัพธ์จาก database จะถูกส่งกลับไปให้ AI เพื่อสรุปเป็นภาษาคน สุดท้าย AI จะตอบกลับผู้ใช้เป็นข้อความที่เข้าใจง่ายตามข้อมูลจริงจากฐานข้อมูล
