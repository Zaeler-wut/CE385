เป็นการสร้าง api สำหรับการดึงข้อมูล สร้างข้อมูล แก้ไขข้อมูล และลบข้อมูล / GET POST PUT DELETE 

1 GET /users/email/:email 
รับค่าอีเมลจาก URL แล้วเอาไปค้นหาในฐานข้อมูลถ้ามีผู้ใช้ ก็จะส่งข้อมูลผู้ใช้กลับไป แต่ถ้าไม่เจอจะตอบกลับว่าไม่เจอผู้ใช้

2 DELETE /users/:id
ลบผู้ใช้ตาม id โดยรับค่า id จากURLแล้วนำไปลบออกจากฐานข้อมูล เมื่อสำเร็จจะส่งข้อมูลผู้ใช้ที่ถูกลบกลับไป

3 POST /posts
สร้างโพสต์ใหม่โดยรับข้อมูลtitle content และรหัสผู้เขียนจาก body แล้วบันทึกในฐานข้อมูล จากนั้นส่งข้อมูลโพสต์ที่สร้างเสร็จกลับไป

4 GET /posts
ดึงข้อมูลโพสต์ทั้งหมดในระบบออกมาแสดงเป็นรายการ

5 GET /posts/:id
ดึงข้อมูลโพสต์ตาม id ที่ระบุในURLถ้าเจอก็จะส่งข้อมูลโพสต์กลับไป แต่ถ้าไม่เจอจะตอบกลับว่าไม่พบโพสต์

6 PUT /posts/:id
แก้ไขข้อมูลโพสต์ โดยรับ id ของโพสต์จาก URL และรับข้อมูลใหม่จาก body เช่น ชื่อเรื่อง เนื้อหา และสถานะการเผยแพร่ แล้วอัปเดตข้อมูลในฐานข้อมูล จากนั้นส่งข้อมูลโพสต์ที่แก้ไขแล้วกลับไป

7 DELETE /posts/:id
ลบโพสต์ โดยรับ id จาก URL แล้วลบโพสต์นั้นออกจากฐานข้อมูล และส่งข้อมูลโพสต์ที่ถูกลบกลับมา
