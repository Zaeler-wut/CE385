4.1  ฟังก์ชัน operation ทำหน้าที่รับชนิดการคำนวณ type และตัวเลข 2 ค่า (a, b) จากนั้นตรวจสอบเงื่อนไขเพื่อเลือกว่าจะบวก ลบ คูณ หรือหารตามที่กำหนด แล้วส่งค่าผลลัพธ์กลับออกมา หากชนิดการคำนวณไม่ถูกต้องจะแสดงข้อความว่า “ไม่มีการดำเนินการนี้”

4.2  ตัวอย่างการทำงานแบบ Asynchronous 2 แบบ คือ Callback และ Promise โดยใช้ setTimeout จำลองการดึงข้อมูลภายใน 2 วินาที
เมื่อครบเวลา จะส่งข้อมูลผู้ใช้กลับมา หากสำเร็จจะแสดงผลข้อมูล แต่ถ้าไม่สำเร็จจะแสดงข้อความ Error ตามรูปแบบของแต่ละวิธี

4.3  เป็นการทำงานแบบ Asynchronous ด้วย Promise และ async/await โดยฟังก์ชัน simulateAsyncOperation จะหน่วงเวลาตามค่า timeout แล้วตรวจสอบว่าเวลามากพอหรือไม่ ถ้า timeout น้อยกว่า 1000 จะเกิด Error แต่ถ้ามากกว่าหรือเท่ากับ 1000 จะสำเร็จและแสดงข้อความว่าเสร็จสมบูรณ์ ผ่านฟังก์ชัน performAsyncTask ที่ใช้ try-catch จัดการผลลัพธ์และข้อผิดพลาด

4.4  เป็นการเรียกข้อมูลจากเซิร์ฟเวอร์ 3 แห่งแบบ Asynchronous โดยใช้ Promise  Promise.any จะเลือกผลลัพธ์ที่สำเร็จตัวแรกที่ได้มา ส่วน Promise.allSettled จะแสดงผลลัพธ์ของทุกเซิร์ฟเวอร์ ไม่ว่าจะสำเร็จหรือเกิดข้อผิดพลาดก็ตาม
