5.1  
GET /students
ใช้สำหรับดึงข้อมูลนักเรียนทั้งหมดจากตัวแปร students แล้วส่งกลับไปให้ผู้ใช้

GET /students/:id
ใช้สำหรับดึงข้อมูลนักเรียนตาม id ที่ส่งมา ถ้าพบจะส่งข้อมูลกลับ แต่ถ้าไม่พบจะส่ง Error 404

POST /students
ใช้สำหรับเพิ่มข้อมูลนักเรียนใหม่ โดยรับ name และ age จาก req.body แล้วบันทึกลงใน students

PUT /students/:id
ใช้สำหรับแก้ไขข้อมูลนักเรียนตาม id โดยเปลี่ยนชื่อ (name) ของนักเรียนคนนั้น ถ้าไม่พบ id หรือไม่ส่งชื่อมาจะเกิด Error

DELETE /students/:id
ใช้สำหรับลบข้อมูลนักเรียนตาม id ถ้าพบจะลบออกจาก students และส่งข้อความยืนยันกลับไป


5.2 validateStudent ทำหน้าที่เช็กข้อมูลที่ส่งมาใน req.body ว่ามี name และ age ครบหรือไม่
ถ้าขาดอย่างใดอย่างหนึ่ง โปรแกรมจะส่ง Error 400 กลับไปพร้อมข้อความ "Invalid data" และจะไม่ไปทำขั้นตอนต่อไป
แต่ถ้าข้อมูลครบ จะเรียก next() เพื่อให้ไปทำงานใน app.post ต่อได้  เมื่อผ่านการตรวจสอบจาก validateStudent แล้ว โปรแกรมจะสร้างข้อมูลนักเรียนใหม่จาก name และ age
จากนั้นนำข้อมูลไปเก็บในตัวแปร students และส่งข้อมูลนักเรียนที่เพิ่มสำเร็จกลับไปให้ผู้ใช้
